# HAFTA 18: WEB SİTESİ OLUŞTURMA
**Sınıf:** 6
**Ünite:** 4 - Ürün Oluşturma
**Süre:** 2 Ders Saati (80 dakika)
**Konu:** Web Sitesi Kavramı, Google Sites, Basit Web Sayfası

---

## 🎯 ÖĞRENME KAZANIMLARI

- Web sitesi kavramını anlar
- Google Sites kullanır
- Basit web sayfası oluşturur
- İçerik ekler (metin, resim, video)
- Web sitesi yayınlar

---

## 📚 KONU ÖZETİ

### Web Sitesi Nedir?

**Tanım:** İnternette erişilebilen sayfalar

**Türleri:**
- Blog (kişisel yazılar)
- E-ticaret (alışveriş)
- Portfolyo (çalışma örnekleri)
- Kurumsal (şirket tanıtımı)

### Web Sitesi Bileşenleri

**1. Ana Sayfa (Homepage):** İlk sayfa
**2. Hakkımda:** Tanıtım
**3. İçerik Sayfaları:** Konular
**4. İletişim:** E-posta, form

### Google Sites

**Platform:** sites.google.com (ücretsiz)

**Özellikler:**
- Sürükle-bırak (kolay)
- Şablonlar
- Resim, video, harita ekleme
- Yayınlama (link paylaşma)
