## 🎯 ÖĞRENME KAZANIMLARI

- Web tarayıcısının ne olduğunu açıklar
- Tarayıcıyı etkin kullanır
- URL, arama motoru kavramlarını bilir
- Güvenli internet kullanım kurallarını uygular

---

## 📚 KONU ÖZETİ

### Web Tarayıcısı Nedir?

**Tarayıcı:** İnternette gezinme programı

**Örnekler:**
- Google Chrome
- Microsoft Edge
- Mozilla Firefox
- Safari

### Temel Kavramlar

**URL:** Web adresi (örn: www.google.com)
**Arama Motoru:** Google, Bing
**Yer İmi (Bookmark):** Favori sayfalar
**Geçmiş (History):** Ziyaret edilen siteler
**Sekme:** Birden fazla sayfa açma

### Güvenli İnternet

**Kurallar:**
1. Kişisel bilgi paylaşma
2. Güvenilmeyen linklere tıklama
3. Ebeveyn izni olmadan indirme yapma
4. Şüpheli sitelere girme

**HTTPS:** Güvenli bağlantı (kilit simgesi)
