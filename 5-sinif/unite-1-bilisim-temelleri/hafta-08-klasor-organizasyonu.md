## 📚 KONU ÖZETİ

### Dosya Arama

**1. Arama Kutusu (Search Box)**
- Windows: Başlat menüsü → Arama
- Dosya Gezgini'nde sağ üst köşe
- Dosya adını yazın → Enter

**2. Gelişmiş Arama**
- Uzantıya göre: `*.jpg` (tüm jpg dosyaları)
- Tarihe göre: Bugün, bu hafta, bu ay
- Boyuta göre: Büyük dosyalar (>1 MB)

**3. Filtreleme**
- Tür: Belgeler, resimler, videolar
- Değiştirme tarihi
- Boyut

### Sıralama

**Sıralama Seçenekleri:**
- **Ada göre:** A-Z veya Z-A
- **Tarihe göre:** En yeni / En eski
- **Boyuta göre:** En büyük / En küçük
- **Türe göre:** Uzantıya göre

**Nasıl Yapılır:**
- Sağ tık → Sırala
- Veya: Sütun başlıklarına tık

### Görünüm Seçenekleri

**Dosya Gezgini Görünümleri:**
- **Çok Büyük Simgeler:** Fotoğraflar için
- **Büyük Simgeler:** Genel kullanım
- **Liste:** Dar alan
- **Ayrıntılar:** Detaylı bilgi (boyut, tarih)

### Dosya Özellikleri

**Bir dosyaya sağ tık → Özellikler:**
- Ad
- Tür (Uzantı)
- Boyut
- Oluşturma tarihi
- Değiştirme tarihi
- Konum (Path)

**Değiştirilebilir:**
- Ad (Yeniden adlandır)
- Öznitelikler:
  - ☐ Salt okunur (Read-only) - Değiştirilemez
  - ☐ Gizli (Hidden) - Görünmez

### Kısayol Tuşları

| Tuş Kombinasyonu | İşlev |
|------------------|-------|
| **Ctrl + C** | Kopyala |
| **Ctrl + X** | Kes (Taşı) |
| **Ctrl + V** | Yapıştır |
| **Ctrl + Z** | Geri Al |
| **Ctrl + A** | Tümünü Seç |
| **Delete** | Sil (Geri Dönüşüme) |
| **Shift + Delete** | Kalıcı Sil |
| **F2** | Yeniden Adlandır |
| **Ctrl + Shift + N** | Yeni Klasör |
| **Alt + Enter** | Özellikler |

### Çoklu Seçim

**1. Art Arda Seçim:**
- İlk dosyayı tıklayın
- Shift basılı tutun
- Son dosyayı tıklayın
- → Aralarındaki hepsi seçilir

**2. Tek Tek Seçim:**
- Ctrl basılı tutun
- İstediğiniz dosyalara tek tek tıklayın

**3. Tümünü Seçim:**
- Ctrl + A

### Dosya Sıkıştırma

**ZIP Dosyası Oluşturma:**
- Dosya/klasörü seç
- Sağ tık → Sıkıştırılmış (ZIP) klasör olarak gönder
- **Faydası:** Boyut küçülür, e-posta eki gönderme kolaylaşır

**ZIP Açma:**
- ZIP dosyasına çift tık
- İçindeki dosyaları görün
- "Tümünü ayıkla" → Çıkart

### Mantıklı Organizasyon İlkeleri

**1. Kategorize Edin:**
```
Belgelerim/
├── Okul/
│   └── (Ders adlarına göre)
├── Kişisel/
│   └── (Hobilerine göre)
└── Projeler/
    └── (Proje adlarına göre)
```

**2. Tarih Kullanın:**
- Klasör adı: `Proje_2025_Şubat`
- Dosya adı: `Ödev_20250207`

**3. Numaralama:**
- `01_Giriş.docx`
- `02_Gelişme.docx`
- `03_Sonuç.docx`

**4. Derinlik Sınırı:**
- Maksimum 3-4 seviye
- Çok derin yapma! (tıklamaktan yorulursun)

**5. Anlam lı İsimler:**

```
tür:belge            → Tüm belgeler
```


**🤔 Felsefi Soru:**
"Fiziksel dünyada düzenli olan biri, dijital dünyada da düzenli olur mu? Yoksa tamamen farklı mı?"

**⚡ Dosya İndeksleme:**
- Windows arka planda tüm dosyaları indeksliyor
- Bu yüzden arama hızlı!
- İlk tarama saatler sürer
- Sonra anında bulur
- **Devre Dışı Bırakma:** Aramayı yavaşlatır ama disk kullanımını azaltır

**🌍 Farklı İşletim Sistemlerinde Yollar:**
```
Windows: C:\Users\Ahmet\Belgelerim
Mac: /Users/Ahmet/Documents
Linux: /home/ahmet/Documents

Windows: \ (ters slash)
Mac/Linux: / (düz slash)
```

**🔐 NTFS İzinleri:**
Windows'ta her dosya/klasörün izinleri var:
- Tam Kontrol
- Değiştirme
- Okuma
- **Örnek:** Ebeveyn kontrolü: Çocuk okuyabilir ama silemez!

**💡 Sembolik Bağlantılar (Symbolic Links):**
Bir dosya/klasörün kısayolu gibi ama daha güçlü:
```
C:\Projeler → D:\Çalışmalarım\Projeler
```
- Gerçek yer D diskinde
- C'den erişim kolay
- İleri düzey kullanıcılar için!

**🎨 Klasör İkonları Özelleştirme:**
- Sağ tık → Özellikler → Özelleştir
- İkon değiştir
- Kapak fotoğrafı seç (fotoğraf klasörleri için)
- Renkli yapın, kolay ayırt edin!

**📊 Disk Kullanım Analizi:**
- WinDirStat (ücretsiz program)
- Hangi dosyalar çok yer kaplıyor?
- Görsel harita
- Gereksizleri temizleyin!

5. **🗂️ Klasör İkonu:** İlk klasör ikonu gerçek manila klasör rengindeydi (sarı-kahverengi). 1995'te mavi oldu (Windows 95).

6. **⚡ En Hızlı Kısayol Kullanıcıları:** Programcılar! Neredeyse hiç mouse kullanmazlar. Her şey klavye ile!

7. **👻 Gizli Dosya Avcıları:** Windows'ta 100+ gizli sistem dosyası var! "System32" klasöründe. Sakın silmeyin!

8. **🎯 MacOS "Spotlight":** Mac'te Cmd+Space = Anında arama. Windows'tan 10 yıl önce geldi! Windows sonradan kopyaladı.
