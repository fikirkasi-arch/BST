## 🚀 HIZLI BAŞLANGIÇ

### Öğretmenler İçin

1. **Sınıf seçin:** `5-sinif/` veya `6-sinif/` klasörüne gidin
2. **README.md** dosyasını açın - Yıllık planın genel görünümü
3. **İlgili ünite** klasörünü açın
4. **Haftalık ders planlarını** inceleyin
5. **Etkinlikleri** kendi sınıfınıza uyarlayın
6. **Değerlendirme araçlarını** kullanın

### Öğrenciler İçin

1. Öğretmeninizin size verdiği **haftalık konuya** gidin
2. **Ders notlarını** okuyun
3. **Etkinlikleri** tamamlayın
4. **Projeleri** geliştirin
5. **Öz değerlendirme** yapın

## 🎓 ÖĞRENME YAKLAŞIMI

### Pedagojik İlkeler

Bu içerikler aşağıdaki modern eğitim yaklaşımlarına dayanır:

1. **Yaparak-Yaşayarak Öğrenme**
   - Uygulamalı projeler
   - Gerçek hayat senaryoları
   - Hands-on etkinlikler

2. **Oyunlaştırma (Gamification)**
   - Eğlenceli yarışmalar
   - Puan ve rozet sistemleri
   - Etkileşimli aktiviteler

3. **Farklılaştırılmış Öğretim**
   - Farklı öğrenme stillerine uygun etkinlikler
   - Kolay-Orta-Zor seviye seçenekleri
   - Öğrenci merkezli yaklaşım

4. **İşbirlikli Öğrenme**
   - Grup projeleri
   - Akran öğretimi
   - Takım çalışması

5. **Proje Tabanlı Öğrenme**
   - Gerçek ürünler oluşturma
   - Problem çözme
   - Yaratıcı düşünme
