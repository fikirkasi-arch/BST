A

Örnek: Okulunuzda tüm bilgisayarlar bir ağa bağlıdır ve yazıcıyı paylaşabilirler.

İlgili Kavramlar: İnternet, LAN, WAN, Router

U

🔌 USB (Universal Serial Bus)

Tanım: Bilgisayara cihaz bağlamak için kullanılan standart bağlantı noktasıdır.

Örnek: USB bellek, mouse, klavye - USB portuna takılır.

İlgili Kavramlar: Flash Drive, Port, Plug and Play

🌐 URL (Uniform Resource Locator)

Tanım: Web sitelerinin internetteki adresidir.

Örnek: https://www.scratch.mit.edu - Scratch'in URL'si

İlgili Kavramlar: Link, Web, Domain

👤 User (Kullanıcı)

Tanım: Bilgisayar, program veya web sitesini kullanan kişidir.

Örnek: Scratch kullanıcısı - hesap açıp proje yapan kişi

İlgili Kavramlar: Account, Login, Username

🎨 UI (User Interface - Kullanıcı Arayüzü)

Tanım: Kullanıcının program veya cihazla etkileşim kurduğu görsel kısımdır.

Örnek: Scratch'in blok alanı, butonlar, menüler - kullanıcı arayüzüdür.

İlgili Kavramlar: GUI, Design, UX

V

📊 Değişken (Variable)

Tanım: Programlamada verileri saklayan isimlendirilmiş kutulardır.

Örnek: Scratch'te "skor" değişkeni - oyundaki puanı saklar.

İlgili Kavramlar: Data, Programming, Value

🎮 Scratch'te Dene

🎥 Video

Tanım: Hareketli görüntü ve ses içeren dijital medya dosyasıdır.

Örnek: YouTube videoları, ders anlatım videoları

İlgili Kavramlar: MP4, Multimedia, Streaming

🦠 Virüs (Computer Virus)

Tanım: Bilgisayara zarar veren kötü amaçlı yazılımdır.

Örnek: Dosyaları silen, bilgileri çalan programlar

İlgili Kavramlar: Malware, Antivirus, Güvenlik

🔒 Güvenli İnternet

🌐 VR (Virtual Reality - Sanal Gerçeklik)

Tanım: Bilgisayar tarafından oluşturulan tamamen dijital üç boyutlu ortamdır.

Örnek: VR gözlükle oyun oynamak - kendinizi başka bir dünyada hissedersiniz.

İlgili Kavramlar: AR, 3D, Headset

📺 Video İzle

W

🌐 Web (World Wide Web - WWW)

Tanım: İnternet üzerinde birbirine bağlı web sayfaları sistemidir.

Örnek: Tarayıcıyla gezdiğimiz tüm siteler - Web'in bir parçasıdır.

İlgili Kavramlar: İnternet, Browser, URL

📱 Widget

Tanım: Küçük, özel amaçlı uygulama veya araç öğesidir.

Örnek: Ana ekrandaki hava durumu widget'ı, saat widget'ı

İlgili Kavramlar: App, GUI, Interface

📶 Wi-Fi

Tanım: Kablosuz internet bağlantı teknolojisidir.

Örnek: Evdeki Wi-Fi - telefonlar ve bilgisayarlar kablosuz internete bağlanır.

İlgili Kavramlar: Wireless, Router, Network

🪟 Windows

Tanım: Microsoft'un geliştirdiği popüler işletim sistemidir.

Örnek: Windows 10, Windows 11 - birçok bilgisayarda kullanılır.

İlgili Kavramlar: OS, Microsoft, GUI

Y

💻 Yazılım (Software)

Tanım: Bilgisayarda çalışan programlar ve uygulamalardır. Elle tutulamaz.

Örnek: Windows, Chrome, Scratch, Word - hepsi yazılımdır.

İlgili Kavramlar: Program, App, Donanım

🔒 Yedekleme (Backup)

Tanım: Önemli dosyaların kopyasını güvenli bir yerde saklama işlemidir.

Örnek: Scratch projelerini bilgisayara kaydetmek - silme durumunda geri yükleyebilirsiniz.

İlgili Kavramlar: Cloud, Recovery, Safety

🎬 YouTube

Tanım: Video izleme ve paylaşma platformudur.

Örnek: Ders videoları, müzik, eğitim içerikleri - milyarlarca video var.

İlgili Kavramlar: Video, Streaming, Social Media

📺 YouTube'a Git

Z

🤐 Zip (Sıkıştırma)

Tanım: Dosyaları daha küçük boyutlara sıkıştırarak saklama formatıdır.

Örnek: 10 dosyayı tek .zip dosyasına sıkıştırıp göndermek

İlgili Kavramlar: RAR, Compression, Archive

🔍 Zoom (Yakınlaştırma)

Tanım: Görüntüyü büyüterek daha yakından görme işlemidir.

Örnek: Haritada yakınlaştırma yapmak, resmi büyütmek

İlgili Kavramlar: Scale, Display, View
